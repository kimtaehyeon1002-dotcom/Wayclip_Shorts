# 일본어 캡션 + 고정댓글 작성기 (jp-caption-writer)

인스타그램(릴스/피드) 일본어 **캡션**과 **고정댓글**을 채널별로 만든다.
`hyperframes-shorts` 와 `remotion-shorts` **양쪽 프로젝트 공용** 스킬.

## 트리거

1. **`/캡션`** 슬래시 커맨드.
2. **결재본 자동 생성** — `output/<channel>/<번호>.mp4` 가 새로 렌더/정규화되어 결재본으로 확정되면,
   같은 작업 흐름에서 **묻지 않고** `<번호>캡션.txt` 를 함께 만든다(아래 "자동 생성 규칙").

그 외 상황에서 자동 발동하지 않는다.

---

## 자동 생성 규칙 (결재본이 나올 때)

> 두 프로젝트의 렌더 워크플로 마지막 단계(hyperframes 판은 normalize-output 까지, remotion 판은 render 직후)에서
> 결재본이 확정되면 **이 텍스트 파일을 항상 같이 만든다.** 사용자가 별도로 "캡션도"라고 말하지 않아도 된다.

- **출력 위치:** 결재본과 같은 폴더 — `output/<channel>/<번호>캡션.txt`.
- **파일명:** `<번호>캡션.txt` (예: 072번 영상 → `072캡션.txt`). 결재본 파일명에 채널 별명/접미사가 붙어 있어도
  (`083 굿바이브.mp4`, `963_v2.mp4` 등) **번호만** 뽑아 `083캡션.txt`, `963캡션.txt` 로 한다.
- **내용:** 한 파일 안에 **캡션 → 고정댓글** 순서, 구분선으로 나눈다(아래 출력 포맷).
- **고정댓글은 채널별 고정 문구**(아래 표) 를 **그대로** 넣는다. 사용자가 "고정댓글 따로/새로" 라고 요청하지 않으면
  변형·재작성하지 않는다.
- **굿무비만** 캡션에 IMDb 평점을 넣는다 → 그 수치만 **웹 검색으로 실제 값 확인** 후 기입. 레디액션 등 다른 영화 채널은 평점을 표기하지 않으므로 IMDb 검색 불필요.
- 결재본을 여러 개 동시에 확정하면 각각에 대해 만든다.

## 다국어 (굿무비 · 스페이스랩 · 레디액션)

이 세 채널은 한 영상당 **일본어 / 대만(번체) / 태국어 / 베트남어 4개 결재본**을 낸다.
결재본이 4개면 **캡션 txt 도 4개** — 각 나라 시청자가 본다는 전제로 **전부 현지화**한다.

- **⚠️ 출력 폴더가 언어별로 분리된다. 영상번호는 전 국가 공통.**
  ```
  output/readyaction/952/952.mp4      + 952캡션.txt   ← 일본어(베이스)
  output/readyaction-tw/952/952.mp4   + 952캡션.txt   ← 대만
  output/readyaction-th/952/952.mp4   + 952캡션.txt   ← 태국
  output/readyaction-vi/952/952.mp4   + 952캡션.txt   ← 베트남
  ```
  **폴더가 언어를 나타내므로 파일명엔 언어 접미사를 붙이지 않는다.** 각 언어 폴더가 일본어 폴더와
  똑같은 모양이라 나라별로 통째로 넘기기 쉽고, 같은 영상은 어느 나라든 **같은 번호**를 쓴다(관리 편의).
- **헤더 줄에 언어 표기:** `[스페이스랩] 047 | TON 618 (繁中)` / `(ไทย)` / `(Tiếng Việt)`
- **본문은 번역이 아니라 재작성.** 일본어 캡션을 직역하지 말 것. 3문단 구조·가치 선점(첫 125자)·
  흥미→공감→행동유도 흐름·CTA 1~2개라는 **구조 규칙만 공통**이고, 문장·비유·어체는 그 나라 정서로 새로 쓴다.
- **고정댓글도 해당 언어로** (아래 표). **@핸들은 그대로 유지** — 언어별 계정이 따로 없으므로
  `@goodmovies_reko` / `@space_lab.note` / `@readyaction_movies` 를 모든 언어판에 그대로 쓴다.
  기존 검증 규칙 동일 적용: `grep -oE "@[A-Za-z0-9_.]+"` 로 우리 채널 핸들인지 확인.
- **레디액션 추천 문단**(`第〈번호〉作目のおすすめは…`)도 언어별 대응 문형으로:
  繁中 `第〈번호〉部推薦，就是這部《작품명》。` / ไทย `เรื่องที่ 〈번호〉 ที่อยากแนะนำ คือ “작품명”`
  / Tiếng Việt `Bộ phim thứ 〈번호〉 mình muốn giới thiệu là “작품명”`
- **굿무비 IMDb 평점은 일본어판 작성 때 한 번만 검색**하고 그 수치를 4개 파일이 공유한다(중복 검색 금지).
- **굿무비 추천 문단**(`そして、第〈번호〉作目のおすすめは…`)도 언어별 대응 문형으로 반드시 넣는다:
  - 繁中 `而第〈번호〉部推薦，就是這部《작품명》。理由是，〜`
  - ไทย `และเรื่องที่ 〈번호〉 ที่อยากแนะนำ คือ “작품명” เพราะว่า〜`
  - Tiếng Việt `Và bộ phim thứ 〈번호〉 mình muốn giới thiệu là “작품명”. Lý do là〜`

## 출력 포맷 (`<번호>캡션.txt` 한 파일)

```
[별명] <번호> | <소재>

〔キャプション〕

(3문단 일본어 캡션 본문 — 채널 규칙대로)


━━━━━━━━━━━━━━━ 📌 固定コメント ━━━━━━━━━━━━━━━

(채널 고정댓글 — 위 표 그대로)
```

- 위는 파일에 적는 내용 그대로. **캡션 먼저, 구분선, 고정댓글 순.**
- 맨 윗줄 `[별명] <번호> | <소재>` 는 사람이 어떤 영상의 캡션인지 식별하는 헤더(붙여둘 것).
- `/캡션` 커맨드로 호출돼 파일을 안 만들고 채팅에만 보여줄 때도 같은 포맷으로 출력.

## 공통 규칙 (캡션 본문)

- **길이:** 모든 채널 공통 **3문단**.
- **언어:** 일본어 전용 (한국어·영어 혼용 금지. 작품명/아티스트명 등 고유명사는 예외).
- **첫 1~2문장에 가치 집약** — 인스타는 캡션 앞 약 125자만 펼쳐 보이므로, 훅/핵심 가치를 앞에 둔다.
- **흐름:** 흥미(메리트) → 공감 → (질문/행동 유도). 숫자·구체어를 넣으면 저장률이 오른다.
- 채널명을 명시 안 하면 어느 채널인지 먼저 묻는다. 소재(곡명·영화명·과학 주제)가 없으면 함께 묻는다.
- `——` 류 대시 인용은 꼭 필요할 때만. 매 캡션 반복 금지.
- CTA는 아래 "CTA 트렌드"에서 채널에 맞게 **자연스럽게 1~2개만** 녹인다. 여러 개를 쌓지 말 것(노이즈).
- **⚠️ SNS 핸들(@xxx)은 무조건 우리 채널 핸들로 교체 (사고 방지 — 필수).** 사용자가 준 원문/번역 소스에 다른 계정 핸들(예 `@wouldyou_woozu`)이 섞여 들어와도 **그대로 옮기지 말 것.** 캡션 본문·CTA·고정댓글 전부 그 채널의 우리 핸들로 통일한다: 굿무비=`@goodmovies_reko`, 레디액션=`@readyaction_movies`, 스페이스랩=`@space_lab.note` (굿바이브·디스힙합은 고정댓글에 핸들 없음 — 본문에 외부 핸들이 오면 삭제). 캡션 저장 직후 `grep -oE "@[A-Za-z0-9_.]+"` 로 외부 핸들 잔존을 한 번 점검할 것.

## CTA 트렌드 (2025–2026 최신, 일본 인스타 기준)

> 2026-06 웹 리서치 반영. 인스타 알고리즘이 "팔로워 밖 도달"을 **공유 > 저장 > 댓글 > 좋아요** 순으로 평가하는
> 흐름이 굳어졌다. 캡션 CTA도 거기에 맞춘다. (출처는 이 파일 맨 아래.)

핵심 3종 — 채널 톤에 맞게 골라 쓴다:

1. **공유(シェア / DMで送る) — 지금 가장 강한 시그널.** 좋아요·댓글의 약 5배 가중. 팔로워 밖 리치의 핵심.
   - 패턴: `この曲/シーン刺さる人に送りたくなる`, `わかる人にこっそりシェア`, `〇〇好きな友達にDMで`.
2. **저장(保存) — "나중에 다시" 가치.** 깊은 관여 지표로 여전히 중요.
   - 패턴: `プレイリスト代わりに保存`, `週末に観るリストへ保存`, `メモ代わりに保存して`.
3. **질문형(問いかけ) — 댓글(양방향) 유도.** 댓글·DM 왕래가 많을수록 리치가 더 퍼진다.
   - 패턴: `あなたはどっち派？`, `この〇〇、知ってた？`, `一番刺さったのはどこ？`.

원칙:
- **억지로 다 넣지 말 것.** 채널 정서에 맞는 1~2개만, 문장에 녹여서.
- 고정 마무리(굿바이브·굿무비·레디액션)는 그대로 두고, **문단 2의 자연스러운 CTA**에 위 메뉴를 활용한다.
- "팔로우하세요"의 직접 반복보다 **공유·저장·질문**이 도달엔 더 효과적(팔로우 유도는 고정댓글이 담당).

채널별 권장 톤:
- **굿바이브:** 공유("この曲、刺さる人いるはず") + 저장(プレイリスト代わりに) 중심. 질문은 고정 마무리에 이미 있음.
- **굿무비:** 저장("週末リストへ") + 친구 태그/공유("一緒に観たい人と"). 결말 스포 금지.
- **레디액션:** 절제. 저장("この余韻を保存") + 은근한 공유 정도. 감성 흐름을 깨는 노골 CTA 금지.
- **스페이스랩:** 질문("知ってた？") + 공유("誰かに話したくなる雑学") + 저장. "이걸 아는 당신은 특별" 뉘앙스.
- **디스힙합:** 저장(プレイリスト入り) + 헤드끼리 공유. 평범·자연스럽게, 억지 쿨함 금지.

## 채널별 규칙

### 1. 굿바이브 (음악 채널)
**성격**: 최신 음악 트렌드 소개, 중독성 있는 곡 큐레이션
**어체**: 친근하고 가볍지만 음악 애정이 느껴지는 말투. 疑問形으로 참여 유도.

**구조**:
1. 문단 1: 곡 소개 — 아티스트 배경, 제작 비화, 가사 의미 등 흥미로운 이야기.
2. 문단 2: 곡의 매력·중독 포인트. CTA(공유·저장)를 자연스럽게 녹임.
3. 문단 3 (고정): 반드시 아래로 끝낸다.

```
皆さんが思う、この曲の「一番の中毒ポイント」はどこですか？
最新の音楽トレンドや情報をもっと知りたい方は、ぜひフォローをお願いします！✨
```

### 2. 굿무비 (영화 큐레이션 @goodmovies_reko)
**성격**: 매일 최고의 영화를 소개하는 큐레이션. **채널 본질 = '영화 추천'** (레디액션과 같은 결). **어체**: 영화 분위기에 맞게 유연, 공감 톤. **주의**: 결말 스포 금지.

**구조**:
1. 문단 1: 영화 소개 — 장르·감독·시대 배경 + 흥미 요소.
2. 문단 2: 핵심 매력, 추천 대상. 은근한 공감 CTA(저장·친구 공유) 포함.
3. 문단 3 (**추천 문단 — 레디액션식, 필수**): 굿무비 본질이 '영화 추천'이므로, 캡션 후반부에 그 작품을 **왜 추천하는지** 담는다. 형식: **`そして、第〈번호〉作目のおすすめは、この『작품명』。その理由は、〜`** 로 시작해 추천 이유를 2~3문장. `〈번호〉` = 영상 번호(예 086 → 第86作目). 결말 스포 금지. (드라마/시리즈면 `作目` 을 자연스럽게 유지하되 하단 라벨은 `ドラマ』` 처럼 소재에 맞춤.)
4. 문단 4 (고정 템플릿): **IMDb 평점은 웹 검색으로 실제 수치** 기입.

```
📈 評価：IMDb：★ [실제평점] / 10
...........................................
毎日最高の映画に出会いたい方は @goodmovies_reko をフォローしてください❤️
...........................................
```

### 3. 레디액션 (고감도 영화 채널)
**성격**: 영화를 깊이 있게·감성적으로. **어체**: 문학적·감성적. **주의**: 결말 스포 금지.

**구조**:
1. 문단 1: 감성적 소개 — 시적 표현, 분위기 묘사.
2. 문단 2: 테마·연출 의도·시대 맥락 등 깊이 있는 해설. (CTA는 절제)
3. 문단 3 (고정 형식): 아래로 끝낸다.

```
✨この映画が「映画名作1000選」に選ばれた理由、それは"[핵심 문구]"にある。[이유 2~3문장]
```

- `"핵심 문구"`: 영화 본질을 꿰뚫는 짧고 강렬한 인용구. 예: `"笑いを武器に、アメリカ社会の深部をえぐる力"`.
- 이어지는 2~3문장: 왜 그 문구가 핵심인지, 무엇이 명작으로 만들었는지 구체적으로. 결말 스포 금지.
- 앞 두 문단의 감성 흐름을 이어받아 마무리.

### 4. 스페이스랩 (과학 지식 채널)
**성격**: 흥미로운 과학 사실을 쉽고 재밌게. "지적 호기심 강한 특별한 사람들이 모이는 채널" 이미지 강화.
**어체**: 호기심 자극, 쉽지만 정확. "이걸 아는 당신은 특별" 뉘앙스를 자연스럽게.

**구조**:
1. 문단 1: 레퍼런스 영상 속 현상/실험을 구체적으로 언급하며 시작. 의외성 훅.
2. 문단 2: 원리·메커니즘 설명. 실생활 비유 활용. 검증된 추가 사실 덧붙임 가능.
3. 문단 3: 더 넓은 과학적 맥락으로 확장 + 마지막에 자연스러운 CTA(질문·공유, 팔로우 유도).

### 5. 디스힙합 (힙합 음악 채널)
**성격**: 힙합 곡·아티스트 소개. **어체**: 평범하고 자연스러운 일본어. 억지 쿨한 힙합체 금지.
단, 힙합 이해·애정이 자연스럽게. 플로우·샘플링·라임·씬 등 용어를 맥락에 맞게.

**구조**:
1. 문단 1: 곡/아티스트 소개 — 씬에서의 위치, 의미 있는 배경.
2. 문단 2: 플로우·가사·비트 등 음악적 특징. 힙합팬에게 왜 중요한지.
3. 문단 3: 아는 사람은 공감할 포인트 / 처음 듣는 사람에겐 추천 이유. 마지막에 간결한 CTA(저장·공유).

## 레퍼런스 캡션 처리

**모든 채널 공통: 사용자는 대부분의 경우 참고할 내용(레퍼런스 캡션/소재)을 함께 준다.** 레디액션뿐 아니라 굿바이브·굿무비·스페이스랩·디스힙합 전부 해당. 입력은 친절하지 않고 짧을 가능성이 높다 — 예: `000번 굿바이브 : 캡션내용~~` 처럼 `<번호> <채널별명> : <참고내용>` 한 줄로 던질 수 있다. **콜론 뒤(혹은 덧붙인) 텍스트가 곧 레퍼런스**라고 전제하고, 포맷을 갖춰 달라고 되묻지 말 것.

- **레퍼런스 있을 때**: 내용·구조·포인트를 기반으로 작성. 직역·복붙 아님 — 채널 정서·어체로 자연스럽게 가공(다른 채널 색이 나면 안 됨).
  - 이미 일본어면: 표현·문장 구조를 충분히 바꿔 중복(표절) 회피, 의미·포인트 유지.
  - 한/영이면: 단순 번역 아닌 일본 인스타 감성으로 재작성.
  - 트리비아가 많으면(영화 채널 등) 나열식(굿무비식 fact 덤프)이 되지 않게, 채널 어체의 흐름에 엮어 취사선택.
- **레퍼런스 없을 때**: 채널 규칙 + 소재로 처음부터.

## 처리 흐름

1. 트리거 감지 (`/캡션` 또는 결재본 생성).
2. 채널·번호·소재 파악 (경로/메시지에서 자명하면 묻지 않음, 없으면 질문).
3. 레퍼런스 유무 확인. (**굿무비만** IMDb 평점 웹 검색 — 다른 채널은 불필요)
4. 번역 톤 모호성(존비·화자관계·감정 등)은 프로젝트 CLAUDE.md 규칙대로 — 불명확하면 `AskUserQuestion`.
5. 채널 규칙으로 3문단 캡션 작성, 트렌드 CTA 1~2개 자연스럽게.
6. 고정 마무리 문구가 있는 채널은 그대로 마무리.
7. 채널 고정댓글을 표에서 그대로 가져옴.
8. `output/<channel>/<번호>캡션.txt` 에 **캡션 → 구분선 → 고정댓글** 포맷으로 저장(또는 채팅 출력).
