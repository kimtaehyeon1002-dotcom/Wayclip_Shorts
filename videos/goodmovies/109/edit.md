# 109 굿무비 — 소스 편집 레시피

『余命10年』(The Last 10 Years, 2022) 예고편 팬편집본을 굿무비 밴드(1080×960)에 맞춰 재편집.
재현: `SRCDIR=<원본있는폴더> bash edit.sh` → `prep-media.mjs … the-last-10-years-2022 --overwrite`.

## 입력

| 파일 | 스펙 | 역할 |
| --- | --- | --- |
| `109 굿무비 원본.mp4` | 1080×720 / 30fps / 26.60s | 본편 (영상 + 음성) |
| `109 굿무비 마지막 컷.mp4` | 1920×1080 / 23.455fps / 2.958s | 마지막 샷 교체용 (커플 석양) |
| ~~`109 굿무비 소스.mp4`~~ | 1920×1080 / 4.187s | **미사용** — 아래 "폐기한 안" 참조 |

## 왜 이렇게 잘랐나

- **박힌 자막(V1):** 원본 하단에 「俺と結婚してください。/ please marry me.」 가 **0.367–3.30s 에만** 박혀 있다
  (전 구간 하단 흰픽셀 스캔으로 확인 — 12s 반짝이·20.9s 밝은 실내는 자막 아님).
  자막 글자는 y 628–718 → **y<628 만 남기는 크롭**으로 제거. 1.125 비율 맞추면 706×628.
  프레이밍이 V2보다 1.15배 조여지지만 **3.333s 에 씬컷이 있어 변화가 컷에 가려진다**.
  1.6–2.1s 고글 샷은 인물이 고개를 숙여 원본에서도 입이 안 보이므로 크롭으로 잃는 것 없음.
- **마지막 샷 교체(V3):** 원본 24.533–26.567 은 남자가 주저앉은 와이드샷이고
  **`as9film` 워터마크가 박혀 있다** → 마지막컷으로 통째 교체(워터마크도 같이 사라짐).
  마지막컷은 1920×1080 안에 콘텐츠 박스 1348×894@(286,92) 로 레터박스돼 있어 그 안에서 다시 1.125 크롭.
- **엔딩(V4):** 원본 음악이 25.35s −20dB → 26.50s −47dB 로 **이미 자연 페이드아웃**한다.
  그래서 소리가 사라지는 지점(26.600)에서 화면 페이드를 시작해 27.200 에 완전 검정,
  0.3s 만 유지하고 끝낸다. 소리와 그림이 같이 빠지므로 별도 처리 불필요.

### 폐기한 안 (2026-08-26)

한때 엔딩 뒤에 `109 굿무비 소스.mp4` 의 음성(「会いたい」/「会いたいよ」)을 암전 위에 얹는 구성을 넣었다가
**사용자 지시로 제거**했다 — "마지막꺼 쓰지 말고 페이드아웃 되고 영상 끝나는 걸로".
그 소스 파일은 그대로 두되 이 영상에는 쓰지 않는다.

## 검증

- 편집본 하단 자막 스캔 재실행 → 전 구간 검출 0.
- 루마: 26.60s 까지 139.3 유지 → 27.20s 16.0(순수 검정) 도달 → 27.50s 까지 평평하게 끝.
- prep-media 측정 −14.27 LUFS → **loudnorm 미적용**, 원본 페이드아웃 그대로 보존.

## 자막

원본 음성은 대사가 「俺と結婚してください」 한 줄뿐(medium 모델로 4초 청크 전수 확인, 나머지는 BGM).
타임스탬프는 원본에 박혀 있던 자막의 등장/소멸(0.367–3.30)을 그대로 사용.
ja→ja 라 `showOriginal()` 이 false → **노란 일본어 한 줄만** 렌더된다(`original` 은 빈 문자열).
